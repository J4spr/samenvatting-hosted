01 Inleiding & Overzicht
Wat is Data Science?

"Everyone talks about it, nobody really knows how to do it, everyone thinks everyone else is doing it, so everyone claims they are doing it." — Dan Ariely over big data

Data science = data omzetten naar informatie door variatie en verbanden te zoeken.

Doelen van data-analyse
  • Wetmatigheden vinden — bijv. 3e wet van Kepler
  • Optimaliseren — bijv. vorm van turbinebladen
  • Beslissingen nemen — bijv. kan klant lening afbetalen?
Soorten analyses (planning)
  • Descriptief — Wat gebeurt er? (P3)
  • Exploratief — Waarom? correlatie, regressie (P4)
  • Confirmatorisch — Zijn we zeker? (P4)
  • Predictief — Wat zal er gebeuren? ML (P4)
💡

Variatie zoeken: weinig variatie = weinig informatie. Verbanden zoeken: onderscheid tussen endogene factoren (je hebt controle: prijszetting, marketing) en exogene factoren (geen controle: inflatie, concurrentie).

Smart Data (Data Engineering)

Data is niet altijd valide — kan onvolledig, inconsistent of met fouten (ruis, extremen) zijn. Verwerking:

  1. Selectie — capteren & verzamelen
  2. Opkuisen / zuiveren — verifiëren & valideren
  3. Verwerking — classificeren & transformeren
  4. Voorbereiding — juist formaat

→ Levert "smart data". Zeer arbeids- en tijdsintensief!

Datapunten & Datareeksen
  • Datapunt (observatie): resultaat van 1 meting op 1 object — heeft een waarde + context
  • Datareeks: reeks observaties van hetzelfde soort, voorgesteld als tabel
  • Variabelen: kolommen in de tabel — bevatten waarden van 1 eigenschap per datapunt
Afhankelijke & Onafhankelijke variabelen
  • Afhankelijke variabele (target): wat je wil verklaren/voorspellen
  • Onafhankelijke variabele: de verklarende factoren
📌

Voorbeeld: "Linux is veiliger dan Windows" → afhankelijk: aanvallen; onafhankelijk: OS-type

Uni- Bi- en Multivariate analyse
  • Univariaat: slechts 1 variabele bekijken (geen afhankelijke)
  • Bivariaat: verband tussen 2 variabelen (1 onafh. + 1 afh.)
  • Multivariaat: verband tussen meerdere variabelen (1 afh. + meerdere onafh.)
03 Meetniveaus
🎯

Belangrijk: het type van een variabele bepaalt hoe ze opgeslagen is. Het meetniveau bepaalt wat je ermee mag doen. Type ≠ meetniveau!

Kwalitatief
Nominaal

Waarden zijn namen of categorieën. Geen volgorde.

Voorbeelden: bloedgroep, computermerk, afstudeerrichting, huisdier

==!=
Kwalitatief
Ordinaal

Categorieën met natuurlijke volgorde, maar geen vaste afstand tussen waarden.

Voorbeelden: militaire rang, tevredenheidsscores, opleidingsniveau, pijnschaal

==!=<>
Kwantitatief
Interval

Getallen met vaste afstand. Geen absoluut nulpunt — verhoudingen zinloos. Negatieve getallen mogelijk.

Voorbeelden: temperatuur °C, balans EUR, tijdstip

==!=<>+-
Kwantitatief
Ratio

Getallen met vaste afstand én absoluut nulpunt. Verhoudingen zijn zinvol. Geen negatieve waarden.

Voorbeelden: temperatuur K, lengte cm, gewicht kg, leeftijd

==!=<>+-×÷
Discreet vs Continu
  • Discreet: enkel bepaalde waarden mogelijk. Nominaal & ordinaal zijn altijd discreet. Bv. RAM in GB, score op 10
  • Continu: alle waarden (binnen grenzen) mogelijk. Enkel kwantitatieve variabelen. Bv. lengte, bitcoin-waarde
  • Quasi-continu: discreet maar enorm veel mogelijke waarden

04 Modelkwaliteit
Betrouwbaarheid

Een meting is betrouwbaar als externe factoren weinig invloed hebben op de meting.

Niet betrouwbaar? → Herhaal de meting meerdere keren en neem het gemiddelde/mediaan.

📐

Bv. examenpunten kunnen verschillen bij studenten met dezelfde kennis; lengtemetingen afwijken door meetmethode.

Validiteit

Een meting is valide als het meet wat het moet meten.

Niet altijd vanzelfsprekend!

❓

Meet een IQ-test echt intelligentie? Hoe meet je assertiviteit of wiskundeaanleg?

Combinaties
  • Betrouwbaar + Valide: ideaal ✓
  • Betrouwbaar maar niet valide: consistent maar meet het verkeerde
  • Niet betrouwbaar + niet valide: waardeloos
  • Niet betrouwbaar maar valide: moeilijk — random fouten rond de ware waarde

📌

⚠

Cumulatieve frequenties zijn alleen zinvol bij ordinale of kwantitatieve variabelen (er moet een volgorde zijn).

Kruistabellen (Pivot tables)

Bivariate frequentietabel: splits 1 variabele op aan de hand van een andere en tel hoeveel iedere waarde voorkomt.

📊

Percentielscores: gebruik cumulatieve percentages als punten = score ten opzichte van de groep. Nadeel: altijd 50% geslaagd ongeacht kennis.

Klassen (Bins) — voor (quasi-)continue variabelen

Continue variabelen worden opgesplitst in klassen (intervallen). Iedere klasse heeft een klassebreedte en een klassemidden. Vuistregel: 5 tot 20 klassen. Na de opsplitsing is het resulterende meetniveau ordinaal.

Sturges

⌈log₂(n) + 1⌉

Eenvoudigste methode. Enkel n nodig.

Scott

b = 3.5 × s / ∛n
k = ⌈(max − min) / b⌉

Gebruikt standaardafwijking s.

Freedman–Diaconis

b = 2 × IQR / ∛n
k = ⌈(max − min) / b⌉

Gebruikt IQR (interkwartielafstand).

Excel

⌈√n⌉

Eenvoudig, geeft meer klassen.

💻

Java — Sturges: Math.ceil(Math.log(n)/Math.log(2) + 1)  |  Scott klassebreedte: 3.5 * s / Math.pow(n, 1/3.0)

06 Visualisaties
📊

Grafieken helpen bij het sneller begrijpen van gegevens, tonen trends, patronen en afwijkingen, en vergemakkelijken vergelijking. Altijd: assen benoemen (naam + eenheid) en een titel geven.

Discrete variabelen
  • Taartdiagram: enkel bij zeer weinig waarden of expres vaag. Slechte keuze bij veel categorieën.
  • Staafdiagram: standaard keuze voor discrete variabelen. Balken naast elkaar, gestapeld of genormaliseerd.
  • Andere: spindiagram, radarplot, wordcloud
Continue variabelen
  • Histogram: staven aan elkaar geplakt, X-as is continu. Vereist klassen. Gebruikt bij interval/ratio.
  • Frequentiepolygoon: verbind alle toppen van de staven. Alternatief voor histogram.
  • Tijdsgebonden data: lijndiagram. Enkel zinvol bij minstens interval meetniveau.
Centrum & Spreiding
  • Boxplot: toont minimum, Q1, Q2 (mediaan), Q3, maximum en uitschieters. Minstens ordinaal.
  • Violin plot: toont ook de distributie/verdeling. Continue variabele vereist.
  • Geen specifieke grafiek voor gemiddelde/standaardafwijking — gevoelig aan uitschieters.
Bivariate grafieken
  • Scatter plot: 2 continue variabelen. Toont correlatie en patroon (lineair of niet).
  • Box plot (bivariaat): 1 continue + 1 discrete variabele. Maak een boxplot per waarde van de discrete variabele.
  • Staafdiagram (bivariaat): beide variabelen discreet. Bars naast elkaar, op elkaar of genormaliseerd.

07 Centrummaten
🎯

Centrummaten zoeken een waarde waarrond alle waarden van 1 variabele schommelen. De keuze hangt af van het meetniveau.

Modus
  • De meest voorkomende waarde
  • Geldig vanaf nominaal meetniveau
  • Eenvoudig te bepalen via frequentietabel
  • Ongevoelig voor uitschieters — modus kijkt enkel naar frequentie, niet naar waarden
  • Bij klassen: indeling kan veel invloed hebben
  • Er kunnen meerdere modi zijn (bimodaal, multimodaal)
Mediaan
  • De middelste waarde na sortering. Bij even n: gemiddelde van de 2 middelste.
  • Geldig vanaf ordinaal meetniveau
  • Ongevoelig voor extremen — enkel volgorde telt, niet de grootte
  • Geen klassen nodig
  • Geen exacte formule → moeilijker voor wiskundige bewijzen
  • Vereist sortering: veel rekenwerk bij grote datasets
Rekenkundig gemiddelde

Formule

x̄ = (1/n) · Σ xᵢ

Geldig vanaf interval meetniveau.

Vanuit frequentietabel

x̄ = (1/n) · Σ fᵢ · xᵢ

fᵢ = absolute frequentie van xᵢ

⚠

Gevoelig voor uitschieters. Bekomen waarde bestaat niet noodzakelijk. Heeft wel een exacte formule → makkelijker voor wiskundige eigenschappen.

Andere gemiddelden

Gewogen gemiddelde

x̄ = (1/Σgᵢ) · Σ gᵢ·xᵢ

Bij studiepunten als gewichten. Iedere waarde weegt anders mee.

Meetkundig gemiddelde

x̄ = (∏xᵢ)^(1/n)

Bij procentuele veranderingen (koersen, groeipercentages). Bv. +5%, +3%, −2%.

Harmonisch gemiddelde

1/x̄ = (1/n)·Σ(1/xᵢ)

Bij snelheden over gelijke afstanden. Bv. heen 120 km/h, terug 100 km/h.

Voortschrijdend gemiddelde

gemiddelde van laatste n waarden

Bij datastroom (stream). Vlakt grillige tijdsgebonden grafieken af.

08 Spreidingsmaten
📐

Spreidingsmaten geven weer hoeveel de data van 1 variabele schommelt rond een centrum. Ze zijn complementair aan centrummaten.

Bereik

Verschil tussen maximum en minimum waarde.

Formule

bereik = max(X) − min(X)

Geldig vanaf interval meetniveau.

⚠

Nadeel: gevoelig aan uitschieters — één extreme waarde verandert het bereik volledig.

Interkwartielafstand (IQR)

Kwantielen zijn varianten op de mediaan: splits de gesorteerde data in gelijke delen.

  • Kwartielen: 4 delen → Q1, Q2, Q3
  • Decielen: 10 delen
  • Percentielen: 100 delen

IQR formule

IQR = Q3 − Q1

Bereik nadat je de 25% grootste en kleinste waarden schrapt. Vanaf ordinaal (kwartielen). IQR zelf vereist interval.

Standaardafwijking

Maat voor de gemiddelde afwijking van alle waarden ten opzichte van het gemiddelde. Geldig vanaf interval.

Poging (probleem)

(1/n) · Σ (xᵢ − x̄)

Probleem: positieve en negatieve afwijkingen heffen elkaar op → altijd 0.

MAD (Mean Absolute Deviation)

(1/n) · Σ |xᵢ − x̄|

Neem absolute waarden. Minder wiskundig handig.

Variantie (s²)

(1/n) · Σ (xᵢ − x̄)²

Kwadrateer de afwijkingen. Andere eenheid (bv. °C² i.p.v. °C).

Standaardafwijking (s)

s = √[(1/n) · Σ (xᵢ − x̄)²]

Neem vierkantswortel van variantie. Zelfde eenheid als data.

🔧

Bessel-correctie (steekproef): In een steekproef onderschat men de echte standaardafwijking. Gebruik s = √[1/(n−1) · Σ (xᵢ − x̄)²] voor betere schatting.

  • De standaardafwijking heeft een formule → wiskundig handig (regressie, kansen, ...)
09 Normalisatie & Uitschieters
Methode 1: Bereik aanpassen (min-max)

Formule

x'ᵢ = (xᵢ − min) / (max − min)

Alle waarden liggen daarna tussen 0 en 1.

  • Voordeel: eenvoudig
  • Nadeel: onderlinge verhoudingen kunnen veranderen; centrum en spreiding veranderen onafhankelijk van andere variabelen
Methode 2: Z-scores (standaardisatie)

Formule

zᵢ = (xᵢ − x̄) / sₓ

Stap 1: trek gemiddelde af → gemiddelde wordt 0. Stap 2: deel door s → s wordt 1.

  • Z=0: waarde = gemiddelde
  • Z=3: 3 standaardafwijkingen boven gemiddelde
  • Z=−0.5: half een standaardafwijking onder gemiddelde
✓

Meest gebruikte methode! Onderlinge verhoudingen binnen variabele blijven bewaard.

Uitschieters (Outliers)

Een uitschieter is een extreem hoge of lage waarde. Oorzaken: menselijke fout, opzettelijk verkeerde invoer, storing meetapparatuur, of echte zeldzame waarde. Uitschieters kunnen ook waardevolle informatie bevatten!

Uitschieters vinden

  • Boxplot of histogram bekijken
  • Verschil mediaan vs gemiddelde
  • Verschil gemiddelde vs getrimd gemiddelde
  • Z-scores: |z| > 3 (of andere grens)
  • IQR-methode: zie formules rechts

IQR-methode voor uitschieters

low = Q1 − 1.5 × IQR
high = Q3 + 1.5 × IQR

Alles buiten [low, high] = uitschieter.
Extreme uitschieter: factor 3 i.p.v. 1.5

10 Kansen
🎲

Kansen zijn relatieve frequenties van een theoretische oneindige steekproef. Ze spelen een grote rol in machine learning (LLM's berekenen kansen per woord) en IT (availability van servers).

Kansen volgens Laplace

Definitie

P(G) = #gunstig / #mogelijk

Geldig bij een "afgelijnd experiment" met gelijke kansen voor alle uitkomsten.

  • 0 ≤ P(G) ≤ 1
  • Som van alle mogelijke uitkomsten = 1 (100%)
  • Kans × 100 = kans in procent (altijd % erbij!)
Voorwaardelijke kansen

Kansen kunnen afhangen van extra kennis:

Notatie

P(A | B)

Kans op A gegeven dat B al bekend is. Als P(A) = P(A|B) dan zijn A en B onafhankelijk.

📊

Voorwaardelijke kansen aflezen uit kruistabellen: kijk naar de rij of kolom van de gegeven voorwaarde.

Rekenen met kansen

Inverse (complement)

P(niet A) = 1 − P(A)

Als P(regen) = 55% → P(geen regen) = 45%

Productregel (EN)

P(A en B) = P(A) · P(B|A)

Bij onafhankelijke gebeurtenissen: P(A en B) = P(A) · P(B)

Somregel (OF)

P(A of B) = P(A) + P(B) − P(A en B)

Aftrekken want A en B kunnen samen voorkomen.

Regel van Bayes

P(A|B) = P(B|A) · P(A) / P(B)

Draai de voorwaardelijkheid om. Basis voor Naïeve Bayes (spamfilter, tekstclassificatie).

💡

Totale kans (wet van totale kansen): P(B) = P(V₁)·P(B|V₁) + P(V₂)·P(B|V₂) + ... Gebruik dit als tussenstap bij Bayes.

11 Correlatie
⚠

Correlatie ≠ causaliteit! Een statistisch verband betekent niet dat de ene variabele de andere veroorzaakt. Spurious correlations bestaan (bv. piraten en globale opwarming, internetexplorer en verkeersongelukken).

Pearson correlatiecoëfficiënt

Voor twee kwantitatieve variabelen (minstens interval). Zet eerst om naar Z-scores, vermenigvuldig en neem het gemiddelde.

Formule

r = (1/n) · Σ zₓᵢ · z_yᵢ

Resultaat altijd tussen −1 en +1.

Waarde rInterpretatie
0Geen lineair verband
0 – 0,2Nauwelijks lineair verband
0,2 – 0,4Zwak lineair verband
0,4 – 0,6Redelijk lineair verband
0,6 – 0,8Sterk lineair verband
0,8 – 1Zeer sterk lineair verband
Rangcorrelatie (ordinale variabelen)

Bij ordinale variabelen: zet eerst om naar rangnummers (kleinste = 1, grootste = n; dubbels krijgen het gemiddelde rangnummer).

Spearman

Pearson op rangnummers

Niet helemaal correct (rangnummers zijn ordinaal, niet interval), maar breed gebruikt. LinkedIn voorbeeld: r=0,763

Kendall (τ)

score / #combinaties

Tel concordante en discordante paren. Correcter voor ordinale data. Niet beschikbaar in Orange.

📌

Stelregel: Interval/ratio → Pearson. Ordinaal → Spearman of Kendall.

12 Regressie
📈

Regressie zoekt de best passende lijn (of curve) door een puntenwolk. Vereist minstens interval meetniveau. Hoge Pearson correlatie is een vereiste voor lineaire regressie. De lijn kan ook gebruikt worden om voorspellingen te maken.

Bivariate lineaire regressie

Vergelijking

y = a + b · x

a = intercept (hoogte). b = richtingscoëfficiënt (slope).

Optimale coëfficiënten

b = r · (sᵧ / sₓ)
a = ȳ − b · x̄

Minimaliseren van de standaardfout se.

Kwaliteitsmaten

Standaardfout (se / RMSE)

se = √[(1/n)·Σ((a+b·xᵢ)−yᵢ)²]

Gemiddelde afwijking van voorspelling. Zo klein mogelijk.

Verklaarde variantie (R²)

R² = 1 − (se² / sᵧ²)

Deel van variatie dat het model verklaart. Zo groot mogelijk (tussen 0 en 1). Bij lineaire regressie: R² = r².

Voorspellingen & Betrouwbaarheid
  • Voorspelling: vul x in de vergelijking in
  • De voorspelling wijkt gemiddeld se af!
  • 68,2% zeker: waarde ligt in [y − se, y + se]
  • 95,5% zeker: waarde ligt in [y − 2·se, y + 2·se]
📌

LinkedIn voorbeeld: a=651,64 ; b=8,91 ; se=511,33 ; R²=0,73. Het model verklaart 73% van het loon via het aantal connecties.

Multivariate lineaire regressie

Vergelijking

y = a + b·x₁ + c·x₂ + d·x₃ + ...

Lineaire combinatie / gewogen som van meerdere onafhankelijke variabelen.

  • Na normalisatie (Z-scores) zijn coëfficiënten vergelijkbaar → zie welke variabele de grootste rol speelt
  • Positieve coëfficiënt: variabele verhoogt de target
  • Negatieve coëfficiënt: variabele verlaagt de target
  • Coëfficiënt ≈ 0: variabele heeft weinig invloed
  • Discrete variabelen via one-hot-encoding omzetten
Niet-lineaire regressie

Als er geen rechte lijn door de punten past:

TypeVergelijking
Kwadratischy = a + b·x + c·x²
Kubischy = a + b·x + c·x² + d·x³
Exponentieely = e^(a+b·x)
Logaritmischy = a + b·log(x)
⚠

Hogere graad = lager se maar risico op overfitting. Kies het eenvoudigste model dat goed genoeg past.

Python Script — Cumulatieve frequenties berekenen
import numpy as np from Orange.data import ContinuousVariable, DiscreteVariable, Domain ## kopie van input data out_data = in_data.copy() ## absolute frequenties ophalen absolute_frequencies = out_data[:,('Count')] ## nieuwe kolommen berekenen relative_frequencies = (absolute_frequencies / np.sum(absolute_frequencies))[:,0] cumulative_frequencies = np.cumsum(absolute_frequencies) cumulative_percentages = cumulative_frequencies / np.sum(absolute_frequencies) * 100 ## kolommen toevoegen aan domain en data invullen ## (herhaal voor elke nieuwe variabele: Relative, Cumulative, Cumulative percentage)

Modus, Mediaan & Gemiddelde in Orange

Via de Group by widget bereken je centrummaten per variabele. Let op: ordinale variabelen worden eerst omgezet naar volgnummers; de gevonden waarden zijn dan rangnummers die je moet terugomzetten.

Stap-voor-stap: centrummaten
  1. CSV inlezen + datatypes juist zetten (Edit Domain)
  2. Volgorde van ordinale variabelen instellen
  3. Dummy variabele aanmaken voor nominale variabelen (Formula)
  4. Continue variabelen in klassen opsplitsen (Discretize)
  5. Alle nominale variabelen behouden; ordinale omzetten naar volgnummers (Continuize)
  6. Modus: Group by → selecteer "mode" voor alle variabelen
  7. Mediaan: Group by → selecteer "median" waar zinvol (ordinaal+)
  8. Gemiddelde: Group by → selecteer "mean" waar zinvol (interval+)
  9. Resultaat bekijken in Data Table

◈ Orange — Uitschieters & Normalisatie
Uitschieters detecteren en verwijderen
  1. CSV inlezen + datatypes juist zetten
  2. Volgorde ordinale variabelen instellen
  3. Dummy variabele aanmaken (Formula)
  4. Q1 en Q3 berekenen (Group by)
  5. Grenzen berekenen: low = Q1 − 1.5×IQR ; high = Q3 + 1.5×IQR
  6. Select Rows: vul de berekende grenzen in als conditie → behoudt rijen zonder uitschieters
⚠

Select Rows verwijdert ook rijen met ontbrekende waarden in de gefilterde kolommen. "Unmatching data" = de rijen mét uitschieters.

◈ Orange — Regressie

Regressie in Orange

Orange ondersteunt bivariate lineaire regressie, multivariate lineaire regressie (met of zonder normalisatie) en niet-lineaire (polynomiale) regressie. Gebruik Select Columns om de afhankelijke variabele in te stellen.

Bivariate lineaire regressie
  1. CSV inlezen + datatypes juist zetten
  2. Select Columns: stel afhankelijke en onafhankelijke variabele in
  3. Scatter Plot: visualiseer het verband (kies de juiste assen)
  4. Linear Regression widget: kies de juiste instellingen
  5. Data Table: bekijk de coëfficiënten (intercept + slope)
  6. Data Table (tweede): bekijk se en R²
  7. Scatter Plot: voeg de regressielijn toe aan de grafiek
  8. Voorspelling: Create Instance → vul waarde in → Predictions widget
Select Columns Scatter Plot Linear Regression Data Table Predictions Create Instance
Niet-lineaire regressie
  1. CSV inlezen + datatypes juist zetten
  2. Scatter Plot: kies afhankelijke en onafhankelijke variabele
  3. Select Columns: stel afhankelijke variabele in
  4. Polynomial Regression widget: probeer verschillende graden (lineair, kwadratisch, kubisch, ...)
  5. Vergelijk R² en se voor elke graad → kies het beste model
  6. Data Table: coëfficiënten per graad bekijken
  7. Predictions: voorspellingen maken
📌

Hogere graad → lagere se maar risico op overfitting. Kies het eenvoudigste model dat goed past.

Scatter Plot Select Columns Polynomial Regression Predictions Data Table
Multivariate regressie (exploratie + model)
  1. CSV inlezen + datatypes juist zetten
  2. Exploratie: Scatter Plot met verschillende variabelenparen; Correlations widget voor alle combinaties
  3. Select Columns: stel de afhankelijke variabele en meerdere onafhankelijke variabelen in
  4. Linear Regression: bekijk coëfficiënten, se en R²
  5. Met normalisatie: Continuize → zet discrete vars om naar one-hot encoding; continue vars naar Z-scores (target NIET)
  6. Vergelijk coëfficiënten na normalisatie om belang van variabelen te vergelijken
💡

Na normalisatie: grote coëfficiënt = grote invloed. Positief = verhoogt target. Negatief = verlaagt target. ≈ 0 = weinig invloed.
